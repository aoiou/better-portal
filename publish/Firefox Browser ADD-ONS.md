## 説明

```
同志社大学のポータル画面および認証システム（doshisha.ex-tic.com）を快適にする拡張機能です。
ポータル画面のレイアウトカスタマイズ（カードの並び替え・非表示等）と、ログイン画面でのユーザー名自動入力・パスワードレス（FIDO2）認証の自動開始を一括で行えます。

【主な機能】
■ ポータル画面カスタマイズ（/idm/user/portal/*）
- サービスカードの自由な並び替え（ドラッグ＆ドロップ、または上下矢印ボタン）
- 不要なサービスカードの非表示化（非表示項目は下部アコーディオンからいつでも復帰可能）
- ナビバー・サブナビ・「アカウント」帯・検索欄の表示/非表示切替
- 「お知らせ」セクションを最下部へ移動するオプション
- Microsoft 365 カードのリダイレクト先URL変更
- 画面読み込み時のチラツキ（FOUC）を抑えた快適なフェードイン表示
- いつでも初期状態に戻せる「設定をリセット」機能

■ ログイン・認証の自動化（/auth/*）
- ユーザー名の自動入力
- 「次へ」ボタンの自動クリック（ON/OFF切替可能）
- パスワードレス（FIDO2）認証の自動開始（ON/OFF切替可能）
- 「パスワード」タブの自動選択（ON/OFF切替可能）
- パスワード入力欄への自動フォーカス
- ショートカットキー（Alt+Shift+D / Mac: Option+Shift+D）によるログイン画面起動
- ポップアップの外観テーマ切替（システム連動 / ライト / ダーク）

【プライバシー・セキュリティ】
ユーザー名およびポータル設定情報はお使いのブラウザ内のストレージ（storage）にのみ保存され、外部サーバーへ送信されることは一切ありません。

※本拡張機能は非公式であり、同志社大学とは関係ありません。
```
