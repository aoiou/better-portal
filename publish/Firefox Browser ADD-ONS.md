## 説明

```
同志社大学のポータル画面および認証システム（doshisha.ex-tic.com）を快適にする拡張機能です。
ポータル画面のレイアウトカスタマイズ（カードの並び替え・非表示・独自カード追加等）、全画面ダークモード対応、およびログイン画面でのユーザー名自動入力・パスワードレス（FIDO2）認証の自動開始を一括で行えます。

【主な機能】
■ ポータル・アカウント管理画面カスタマイズ（/idm/user/*）
- サービスカードの自由な並び替え（直感的なドラッグ＆ドロップ、または上下矢印ボタン）
- 不要なサービスカードの非表示化（非表示項目は下部アコーディオンからいつでもワンクリック復帰可能）
- オリジナルサービスカードの作成・追加（タイトル・URL・アイコン［絵文字 / 画像URL / デフォルト］を自由に設定、リアルタイムプレビュー、別タブ直接遷移）
- 作成したオリジナルカードの編集・削除・並び替え・非表示管理
- 各種UI要素の表示/非表示切替（ナビバー、サブナビ、「アカウント」帯、検索欄）
- 「お知らせ」セクションを最下部へ移動するオプション
- Microsoft 365 カードのリダイレクト先URL変更（専用モーダルUIで簡単設定）
- 画面読み込み時のチラツキ（FOUC）を抑えた快適で滑らかなフェードイン表示
- いつでも初期状態に戻せる「設定をリセット」機能（作成したオリジナルカードは保持）

■ ログイン・認証の自動化（/auth/*）
- ユーザー名の自動入力
- 「次へ」ボタンの自動クリック（ON/OFF切替可能）
- パスワードレス（FIDO2）認証の自動開始（ON/OFF切替可能、Windows Hello等）
- 「パスワード」タブの自動選択（ON/OFF切替可能）
- パスワード入力欄への自動フォーカス（標準搭載）
- ショートカットキー（Alt+Shift+D / Mac: Option+Shift+D）によるログイン画面起動

■ 全画面ダークモード対応（/auth/*, /idm/user/*, /imgmtx/*）
- ポータル画面、アカウント管理画面、ログイン・認証画面、マトリクス認証画面、および拡張機能ポップアップの全画面に対応
- OSのカラー設定に自動連動する「システム設定」のほか、「ライト」「ダーク」をいつでも自由に切り替え可能
- お知らせや各種アラート通知、ボタンなどの視認性にも最適化された目に優しいデザイン

【プライバシー・セキュリティ】
ユーザー名およびポータル設定情報はお使いのブラウザ内のストレージ（storage）にのみ保存され、外部サーバーへ送信されることは一切ありません。

※本拡張機能は非公式であり、同志社大学とは関係ありません。
```
