# ストアの掲載情報

## 商品の詳細

### 説明

```
同志社大学のポータル画面（doshisha.ex-tic.com）のレイアウトを自由にカスタマイズできる拡張機能です。
使わないサービスカードの非表示化や、ドラッグ＆ドロップによる自由な並び替え、ヘッダー・ナビバー等の非表示により、ポータル画面をシンプルで使いやすく整理できます。

【主な機能】
- サービスカードの自由な並び替え（ドラッグ＆ドロップ、または上下矢印ボタン）
- 不要なサービスカードの非表示化（非表示項目は下部アコーディオンからいつでも復帰可能）
- ナビバー・サブナビ・「アカウント」帯・検索欄の表示/非表示切替
- 「お知らせ」セクションを最下部へ移動するオプション
- 画面読み込み時のチラツキ（FOUC）を抑えた快適なフェードイン表示
- いつでも初期状態に戻せる「設定をリセット」機能

【プライバシー・セキュリティ】
設定情報（並び順や非表示状態）はお使いのブラウザ内（storage）にのみ保存され、外部サーバーへ送信されることは一切ありません。

※本拡張機能は非公式であり、同志社大学とは関係ありません。
```

# プライバシー

## 単一用途

```
同志社大学ポータル画面（https://doshisha.ex-tic.com/idm/user/portal/*）において、サービスカードの並び替え・非表示や各種UI要素の表示カスタマイズを行うこと。
```

## 権限が必要な理由

### storage が必要な理由

```
ユーザーがカスタマイズしたカードの並び順、非表示項目、ナビバーや検索欄等の表示設定をブラウザ内に保存するために使用します。外部サーバーへの送信は一切行いません。
```

### ホスト権限 が必要な理由

```
同志社大学ポータルページ（https://doshisha.ex-tic.com/idm/user/portal/*）においてのみコンテンツスクリプトとスタイルを実行し、レイアウトのカスタマイズ機能を提供するために必要です。他のウェブサイトでは動作しません。
```
