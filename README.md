# Better Portal for Doshisha

同志社大学のポータル画面（`https://doshisha.ex-tic.com/idm/user/portal/*`）のレイアウトカスタマイズ（並び替え・非表示等）と、認証システム（`https://doshisha.ex-tic.com/auth/*`）におけるログイン・認証の自動化を一括で行うブラウザ拡張機能です。

## 🌟 特徴

### 1. ポータル画面カスタマイズ機能（`/idm/user/portal/*`）
- **直感的なドラッグ＆ドロップ並び替え**: サービスカードをマウスで掴んで好みの位置へ自由に並び替え可能。青紫色のインジケーターで挿入位置も一目で分かります。
- **ボタン操作（▲/▼）での並び替えにも対応**: ドラッグ操作がしづらい環境や微調整のために、各カードにワンクリック移動ボタンを完備。
- **不要な項目の非表示化**: 使わないサービスカードをワンクリックで非表示にして、画面をシンプルに整理。
- **非表示項目の折りたたみ管理（アコーディオン）**: 非表示にした項目はページ下部の折りたたみセクションに隔離。件数バッジ付きで、いつでもワンクリックでメイン画面に復帰可能。
- **各種UI要素の表示/非表示切替**:
  - ナビバー（上部バー）
  - サブナビ
  - 「アカウント」タイトル帯
  - 検索欄
- **「お知らせ」の位置移動**: 画面上部の大部分を占める「重要なお知らせ」をポータル最下部に移動させ、目的のサービスカードへ素早くアクセス可能。
- **Microsoft365のリダイレクト先URL変更**: Microsoft365カードクリック時の遷移先URL（OneDriveやSharePointなど）を任意のURLにカスタマイズ可能。
- **チラツキ防止（FOUC対策）**: ページ読み込み時にオリジナルのレイアウトが一瞬表示されるのを防止し、整ったレイアウトで滑らかにフェードイン表示。
- **ワンクリックリセット**: 設定を初期状態に戻したいときは「設定をリセット」ボタンでいつでも復元可能。

### 2. ログイン・認証自動化機能（`/auth/*`）
- **完全自動入力**: ログインページを開くだけで、登録されたユーザー名を即座に自動入力。
- **「次へ」ボタン自動クリック（ON/OFF切替可能）**: ユーザー名入力後、自動で「次へ」ボタンを押してパスワード画面へ進むオプションを搭載。
- **パスワードレス認証の自動開始（ON/OFF切替可能）**: 「次へ」押下後にパスワードレス（FIDO2）認証画面が表示された場合、自動で「パスワードレス認証」ボタンをクリックしてパスキー認証（Windows Hello等）を自動起動。
- **「パスワード」タブの自動選択（ON/OFF切替可能）**: FIDO2が利用可能な環境でも、パスワード入力を優先したい場合に「パスワード」タブを自動で選択して表示。
- **パスワード入力欄への自動フォーカス（標準搭載）**: パスワード画面表示時に自動で入力欄（`#password`）にフォーカスを当て、キーボードから手を離さずに即座に入力開始可能。
- **ショートカット起動（`Alt+Shift+D`）**: ブラウザ内のどこからでも、ショートカットキー一発で同志社ログイン画面を開けます（Mac: `Option+Shift+D`）。
- **動的レンダリング・SPA・jQuery対応**: Extic独自のjQuery `.data()` 画面遷移に対応した確実なStep判定と `MutationObserver` 監視により、遅延表示される入力欄や画面切り替えにも確実・安全に対応。
- **外観テーマ切替（システム連動／ライト／ダーク）**: ポップアップ設定画面はOSのカラーテーマ設定に自動連動する「システム設定」のほか、「ライト」「ダーク」をいつでも自由に切り替え可能。

### 3. 共通仕様
- **Manifest V3 準拠**: 最新の Chrome / Firefox / Edge / Brave 等のブラウザ仕様に対応。
- **安全な同期/ローカルストレージ**: すべての設定値とユーザー名はブラウザ内の `browser.storage.sync`（または `local`）にのみ安全に保存され、外部サーバーへ送信されることは一切ありません。

### 2. ソースコードから読み込む場合（開発・カスタマイズ時）

機能開発やカスタマイズを行う場合は、以下のデベロッパーモードを用いた読み込み手順をご利用ください。

#### Google Chrome / Microsoft Edge / Brave 等（Chromium系ブラウザ）
1. 本リポジトリをクローンするか、ZIPファイルをダウンロードして展開します。
2. ブラウザで拡張機能管理画面を開きます。
   - Chrome: `chrome://extensions/`
   - Edge: `edge://extensions/`
3. 画面右上にある「**デベロッパー モード**」を有効にします。
4. 左上に表示される「**パッケージ化されていない拡張機能を読み込む**」ボタンをクリックします。
5. リポジトリ内の **`src` ディレクトリ**（※リポジトリのルートではなく、必ず `src` フォルダ）を選択して読み込みます。

#### Mozilla Firefox / Zen / Floorp 等（Firefox系ブラウザ）
1. アドレスバーに `about:debugging#/runtime/this-firefox` と入力して開きます。
2. 「**一時的なアドオンを読み込む...**」ボタンをクリックします。
3. リポジトリ内の **`src/manifest.json`** ファイルを選択します。  
   *※ 一時的なアドオンとして読み込まれるため、ブラウザ再起動時には再読み込みが必要になります。*

## 💡 使い方

### ログイン自動化の設定（ポップアップ画面）
1. ツールバーの拡張機能アイコン（紫色の「D」アイコン）をクリックしてポップアップを開きます。
2. **「自動入力するユーザー名」** 欄に、ログインで使用するユーザー名を入力します。
3. お好みに応じて各種オプションのスイッチを設定します：
   - **「自動で「次へ」に進む」**: ユーザー名入力後、自動的に「次へ」ボタンを押します。
   - **「パスワードレス（FIDO2）設定者向け」グループ**（FIDO2認証が登録されているアカウント用）:
     - **「パスワードレス認証を自動開始」**: パスワードレス画面が表示された場合、自動的に「パスワードレス認証」ボタンを押してWindows Helloやセキュリティキーを起動します。
     - **「「パスワード」タブを自動選択」**: パスワードレス画面ではなく、パスワード入力タブを優先して自動選択します（FIDO2自動開始と排他で安全に制御）。
   ※ パスワード画面が表示された際は、設定不要で常に自動的にパスワード入力欄へフォーカスが当たります。
4. 入力内容や各種オプションはすべて**自動保存**されます。
5. **ショートカットキー `Alt+Shift+D`**（Mac: `Option+Shift+D`）を押すか、ポップアップ右上のバッジをクリックすれば、どこからでも即座にログイン画面（`https://doshisha.ex-tic.com/auth/session`）を開けます。

### ポータル画面のレイアウト編集（ポータル画面上）
1. 同志社大学ポータル（`https://doshisha.ex-tic.com/idm/user/portal/`）にアクセスします。
2. 画面右下に表示される紫色の**歯車ボタン（⚙）**をクリックすると、「**編集モード**」が起動します（画面上部に紫色の帯が表示されます）。
3. 編集モード中に以下の操作が可能です：
   - **並び替え**: カードをドラッグ＆ドロップするか、カード中央の「▲」「▼」ボタンをクリックして順序を入れ替えます。
   - **カードの非表示**: カード上の赤色の「非表示にする」ボタンをクリックします。
   - **非表示カードの復帰**: 画面下部に表示される「非表示の項目」アコーディオンを開き、緑色の「表示する」ボタンをクリックします。
   - **Microsoft365のリンク先変更**: Microsoft365カード上の「リンク先を変更」ボタンをクリックし、遷移したいURL（例: `https://doshishaacjp-my.sharepoint.com/my`）を入力します（空欄にするとデフォルトに戻ります）。
   - **ナビバー・検索欄等の非表示**: ナビバー、サブナビ、「アカウント」帯、検索欄の上に重なって表示されるボタンをクリックして表示/非表示を切り替えます。
   - **お知らせの移動**: お知らせエリア上の「お知らせを一番下に移動」ボタンをクリックします。
4. 変更した設定は**すべて自動保存**されます。
5. もう一度右下の歯車ボタン（⚙）をクリックすると編集モードが終了し、カスタマイズ後のすっきりとしたポータル画面を利用できます。
6. 設定を初期状態に戻したい場合は、編集モード中に歯車ボタンの上に現れるオレンジ色の「**設定をリセット**」ボタンをクリックします。

## 🔒 プライバシーポリシー

本拡張機能は、ユーザーのプライバシーを尊重し、個人情報や認証情報（パスワード等）を外部サーバーへ収集・送信することは一切ありません。すべての設定データとユーザー名はブラウザ内の同期/ローカルストレージにのみ安全に保存されます。

- **免責事項・非公式について**:

- **キャンセルボタン押下時の動作について**:  
  ログイン認証画面において、パスワード画面やパスワードレス（FIDO2）認証画面から「キャンセル」ボタンを押して最初のユーザー名入力画面に戻った場合、**拡張機能は意図的に自動入力・自動遷移を停止します**。これは別アカウントでの手動ログイン等の操作を妨げないための仕様です。
- **大学側のポータル・認証画面の仕様変更について**:  
  同志社大学ポータル画面および認証画面のHTML構造（要素のID名やクラス名）が大幅に変更された場合、一時的に機能しなくなる可能性があります。
